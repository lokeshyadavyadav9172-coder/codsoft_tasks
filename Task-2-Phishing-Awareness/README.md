\# PhishGuard - Phishing Awareness Training Module



\## CODSOFT Internship - Task 2



PhishGuard is an interactive web-based cybersecurity awareness training module designed to educate users about phishing attacks and social engineering techniques.



\## Features



\- Phishing awareness introduction

\- Suspicious email detection

\- Fake login page awareness

\- Fraudulent website identification

\- Social engineering techniques

\- Real-world phishing case studies

\- Practical cybersecurity tips

\- Interactive 5-question quiz

\- Automatic quiz scoring

\- Progress tracking

\- Security checklist

\- Responsive design for desktop and mobile



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Google Fonts
